## Platform

## Product Purpose

AEGIS is a local drone test facility for inspecting a procedural quadcopter, comparing engine profiles in the same flight course, and reviewing recorded runs.

## Operating Context

A run starts from the hangar configuration and uses the same profile for a timed five-gate course. The mission console reads the resulting telemetry and SQLite records. Desktop keyboard and on-screen flight controls are both part of the primary workflow.

## Capabilities and Constraints

The benchmark brief supplies the audience and technical constraints. The facility works without credentials or external runtime assets. A fixed seed, camera and scene time provide repeatable benchmark views. The operator can separately measure live frame timings.
